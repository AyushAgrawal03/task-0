# Task 0: Python Fundamentals, Data Analysis & Git

**Author:** Ayush Agrawal

## Description
This repository contains solutions for Task 0, serving as an introduction to Python, data analysis, and Git workflows. The project covers list manipulation, control flow logic, and a linked data analysis pipeline using NumPy, Pandas, and Matplotlib.

## Setup Instructions
Ensure you have Python installed on your system. You must install the required external libraries before running the data analysis scripts.

Run the following command in your terminal to install the dependencies:
`pip install numpy pandas matplotlib`

## How to Run the Solutions
Execute each script individually from the root directory of the repository using your terminal:

* **Q1 (List Analyzer):** `python q1.py` *(requires user input)*
* **Q2 (List Methods):** `python q2.py`
* **Q3 (Prime Numbers):** `python q3.py` *(requires user input)*
* **Q4 (NumPy Basics):** `python q4.py`
* **Q5 (Pandas Analysis):** `python q5.py`
* **Q6 (Matplotlib Visualizations):** `python q6.py`
